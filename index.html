How to play

Eat the fruit to grow. Each fruit is worth 10 points times your level, and every 5 fruit the snake speeds up. A golden fruit appears now and then for a few seconds and is worth five times as much. Don't run into yourself — or, in Classic mode, the walls.

Install it as an app

Snake works offline once it has loaded, and opens in its own window when installed.

  • Chrome or Edge: click Install in the toolbar above, or the install icon at the right of the address bar.
  • Safari on Mac: choose File → Add to Dock.
  • iPhone and iPad: tap Share, then Add to Home Screen.
  • Android: open the browser menu and tap Install app or Add to Home screen.
